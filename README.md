# AWS CloudOps Incident Management & Automated Remediation Platform

A hands-on AWS Cloud/DevOps/SRE project designed to demonstrate
infrastructure monitoring, incident detection, event-driven automation,
alerting and automated remediation.

## Architecture

The platform uses AWS services including:

- Amazon EC2
- Amazon VPC
- AWS Lambda
- Amazon API Gateway
- Amazon DynamoDB
- Amazon CloudWatch
- Amazon EventBridge
- Amazon SNS
- Amazon S3
- AWS IAM
- AWS CloudTrail

Infrastructure will be provisioned using Terraform and application
deployment automated through CI/CD.

## Project Objectives

- Monitor cloud infrastructure and applications
- Detect operational failures automatically
- Generate and track incidents
- Send real-time operational alerts
- Perform controlled automated remediation
- Implement least-privilege IAM security
- Provision infrastructure using Terraform
- Demonstrate practical AWS troubleshooting
